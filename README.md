# Women and children

Lectura de cómo la 81.ª Asamblea General de la ONU dice «mujeres y niños», y de los marcos agentes, víctimas y mixto. El sitio está en inglés (`/en/`) y en español (`/es/`).

## Desarrollo

```bash
npm install
npm run dev
npm run build
```

`npm run build` genera una exportación estática en `out/`.

## Cómo citar

Zappe, Macarena, and Agustina Nahas. Women and children in the 81st General Assembly.

## Base de datos

Las filas codificadas están en [`public/database.csv`](public/database.csv) y en la [hoja de cálculo](https://docs.google.com/spreadsheets/d/1fx8tO7nBxuz6bdsTokH6erg1JZIXtJxVR8XKPVqlWx4/edit?gid=746900357#gid=746900357).
